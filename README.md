# 《終戰－回溯餘音》Android 版隱私政策

最後更新：2026-10-11
生效日期：2026-10-11 
政策版本：FinalBattleRPG-Ver.0.3.0

本隱私政策適用於月隱星輝工作室提供的《終戰－回溯餘音》Android 手機遊戲，包括內部測試版本。

我們會依您使用的功能處理必要資料。大部分核心玩法可使用裝置上的本機存檔；Google 登入、雲端服務與廣告有各自的使用條件及選擇。請閱讀遊戲首次顯示的資料使用說明，並依您的意願選擇選填項目。

## 一、資料與用途

| 情境 | 處理的資料 | 用途及處理位置 |
|---|---|---|
| 本機遊玩 | 角色、背包、裝備、技能、資源、進度與遊戲設定 | 保存在本機，用於遊玩與讀取存檔；使用雲端備份時，相關遊戲資料才會依該功能上傳 |
| Google Play Games 登入 | 遊戲玩家識別碼、顯示名稱、登入／驗證資訊 | 由 Google Play Games 與 Unity Authentication 協助驗證身分，連結對應的遊戲帳號；我們不要求您向遊戲提供 Google 密碼 |
| Unity 線上功能 | Unity 玩家識別碼、雲端存檔、遊戲狀態、排行榜分數、PVE 戰鬥／活動結果、雲端資源餘額及必要的請求／錯誤資訊 | 由 Unity Gaming Services 提供帳號驗證、備份、排行榜、PVE、設定下載、獎勵驗證及重複請求防護 |
| 廣告 | 裝置與廣告識別資訊、IP 位址、裝置／作業系統／應用程式資訊及廣告互動資料；實際項目依啟用的廣告來源與其 SDK 而異 | Unity LevelPlay 與啟用的廣告來源提供廣告、處理個人化選擇、衡量廣告表現及防範無效流量 |
| 廣告獎勵確認 | 遊戲玩家識別碼、廣告使用者識別碼、claim／event 識別碼、版位、獎勵種類與數量、時間及處理結果 | Cloudflare Workers、Queue、D1 與 Unity Cloud Code／Cloud Save／Economy 用於確認廣告完成、重試、避免重複領獎及更新遊戲餘額 |
| 待確認獎勵 | 玩家識別碼、領取編號、版位與到期時間 | 裝置本機保存尚待伺服器確認的紀錄；回到遊戲、重新登入後可繼續查詢，不需要因查詢失敗而重播廣告 |
| 隱私選擇 | 告知／政策版本、選填偏好及確認時間 | 本機保存您的選擇，在內容更新時要求重新確認，並控制可選功能 |
| 技術診斷 | 應用程式與裝置資訊、錯誤／崩潰及執行資訊，視目前啟用的 Unity 診斷功能而定 | 用於找出故障與改善穩定性；診斷資料與選填的遊戲行為分析不是同一項功能 |

本 Android 版本不以 Discord 使用者名稱或 Discord user ID 作為手機版登入資料。

## 二、選擇、廣告與測試流量

您可以拒絕選填的廣告資料使用與遊戲分析，仍使用本機核心玩法。您可在遊戲的隱私設定中變更選擇。本版本在尚未取得有效廣告選擇時不請求廣告；撤回後會停止後續廣告請求，已處理的資料仍依本政策及服務提供者適用規則處理。

獎勵型廣告由您主動選擇觀看。獎勵以伺服器確認結果為準；關閉廣告、本機顯示成功或查詢逾時不會自動保證發獎。Banner 依遊戲頁面及目前設定顯示。

內部測試可能使用 Unity Ads 的測試廣告。**測試廣告仍可能連線第三方並處理裝置、廣告與驗證資料**，測試模式不代表完全不傳送資料。當廣告功能維持封鎖時，本遊戲不會因為您閱讀本政策就自動開放廣告。

目前專案尚未實作獨立的 Unity Analytics 遊戲事件上傳服務。若日後加入遊戲行為分析，會更新告知內容與政策，並依適用要求重新取得選擇；Unity 診斷及廣告成效處理仍依各自用途說明。

## 三、服務提供者與資料揭露

為提供您選用的功能，本遊戲使用下列服務；它們可能依服務運作需要接收及處理相關資料：

- **Google／Google Play Games**：Android 配送、遊戲登入及其平台服務。[Google 隱私權政策](https://policies.google.com/privacy)
- **Unity Gaming Services**：Authentication、Cloud Save、Cloud Code、Economy、Leaderboards、Remote Config，以及啟用的 Unity 診斷功能。
- **Unity LevelPlay、Unity Ads 與實際啟用的廣告來源**：廣告供應、成效衡量與無效流量防護。[Unity 玩家與應用程式使用者隱私政策](https://unity.com/legal/game-player-and-app-user-privacy-policy)
- **Cloudflare**：接收廣告獎勵回呼並保存／傳送待確認工作與處理紀錄。[Cloudflare 隱私政策](https://www.cloudflare.com/privacypolicy/)

我們不會為販售玩家個人資料而交易資料。為提供上述功能所需的委外處理、依法提供資料，以及經您明確要求的處理，會依相應目的進行。由於使用雲端服務，資料可能在您所在國家／地區以外處理；實際處理位置及服務提供者採行的保護措施依其服務與適用安排而定。

排行榜或 PVE 排名功能可能讓其他使用者看到您的遊戲顯示名稱、排名與成績。請避免在遊戲顯示名稱中填入不希望公開的資訊。

## 四、保存與刪除

本機遊戲資料通常保留至您使用遊戲提供的重設功能、清除 App 資料或解除安裝；Android 系統備份若啟用，可能另依您的系統設定處理。移除 App 不會自動刪除先前已上傳的雲端資料。

線上帳號、雲端進度、排行、PVE 及廣告驗證紀錄依提供功能、處理申訴、避免重複發獎及維護安全所需期間保存。**待確認獎勵的 600 秒處理期限不是所有相關資料的保存期限。**

您可透過 "聯絡我們" 欄位中的電子郵件向我們提出查詢、更正、刪除帳號及相關遊戲資料的請求。我們會核對您的帳號與請求範圍，並於 30日 內回覆。請提供可識別遊戲帳號的資訊，但不要傳送 Google 密碼、登入 token 或其他憑證。

若部分資料因適用法令、爭議處理或防詐需求必須保留，我們會說明資料類別、原因與適用保存期間。刪除本遊戲雲端資料不會刪除您的 Google 帳號；您亦可透過 Google／Unity 提供的管道管理其依自身政策處理的資料。

## 五、安全、年齡與政策更新

我們會採取符合本遊戲規模的存取控制與傳輸保護，使用 HTTPS 與伺服器驗證處理線上請求，並限制維運資料的存取。任何網路或儲存系統都無法保證絕對安全。

若功能或資料處理方式改變，我們會更新本頁的版本與日期。重要變更會透過遊戲內告知；需要重新選擇的項目，會在適用功能啟用前提示。
